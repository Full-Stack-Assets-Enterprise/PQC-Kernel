# Changelog

## 0.1.0 — 2026-08-29

- Added dependency-free Python 3.11 evidence models with deterministic IDs.
- Added token-aware lexical C/C++ source detection for 30 OpenSSL/PKCS#11 API symbols.
- Added argument-marker normalization for RSA, EC/DH, ML-KEM, ML-DSA, and SLH-DSA contexts.
- Added `readelf`-backed ELF undefined-dynamic-symbol detection.
- Added per-artifact `FULL`, `PARTIAL`, `FAILED`, and `SKIPPED` coverage semantics.
- Added a source-backed, applicability-gated US federal PQC transition policy profile.
- Added write-once JSON/JSONL bundle creation, embedded rule/policy snapshots, and Markdown dossier projection.
- Added bundle integrity verification, deterministic-record verification, reference checks, and a separately retainable root receipt.
- Added 11 tests, including a compiled dynamic-link fixture and tamper detection.
